Module 5: Data Visualization and Communication
Use data and a one-page brief to make a clear, responsible message for a decision-making audience. Read Rise Module 5, Sections 5.3–5.4, select one pathway, and complete the Module 5 notebook template.
Start here
1. Download the Module 5 .ipynb template from this GitHub folder. Open Google Colab, upload the downloaded notebook, and select File → Save a copy in Drive. No local Python setup is needed.
2. Set the pathway in the notebook. Foundational loads the [synthetic event file](./Data/post_overdose_data.csv) automatically. Applied requires an appropriate public aggregate source and a documented ingestion and cleaning approach; the synthetic file is available for offline practice.
3. Run cells in order, answer the prompts, review the chart and brief, and rerun the final export. Running the code alone does not complete the written work.
4. Use only approved public aggregate or supplied synthetic data. Do not upload PHI or sensitive records.
Interpret the supplied data carefully
post_overdose_data.csv contains synthetic event records, not verified deaths or a population denominator. The Foundational chart shows monthly counts of recorded opioid-involved events. Do not describe them as overdose mortality rates or calculate a rate per 100,000 without a matching numerator and population denominator. Check the actual provisional flags before describing uncertainty.
