WISER Training Modules

This repository contains the computational training materials developed for the WISER Training Program. The materials support hands-on learning activities in data science, machine learning, natural language processing, and responsible artificial intelligence (AI) using health and substance use research examples.

The repository is designed to complement the WISER online training modules by providing Google Colab notebooks, synthetic datasets, templates, and supporting resources that learners can use to complete applied activities without requiring a local programming environment.

About WISER
WISER is an interdisciplinary training program designed to build practical skills for applying data science and AI methods to substance use and health research.

The training emphasizes:
Reproducible and transparent research
Responsible use of AI and machine learning
FAIR data principles
Ethical and stigma-free approaches to substance use data
Practical application of computational methods
Communication of analytical findings to scientific and nontechnical audiences
